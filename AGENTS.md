# pi.lot Project Guidelines

## Core Principles

- Keep code as minimal and simple as possible.
- Maintainability over cleverness.
- Leverage built-in pi coding agent features whenever possible — avoid reinventing functionality.
- Do not add unnecessary features.
- This project is a lightweight Telegram bridge to the pi coding agent, bundled with only the essential skills needed for an assistant agent.

## Scope

- Telegram bridge to pi coding agent.
- Essential assistant skills only.
- No bloat, no custom implementations of things the agent already provides.
